什么是便利店支付

导入便利店支付后，即可接受购买者在便利店门店以现金支付在线购买的商品。
您既可以使用 fincode API 获取条形码图片并将其嵌入自有 GUI，也可以使用已构建完成的重定向支付页面，通过少量编码快速开始使用便利店支付。
fincode 支持在以下便利店进行支付。
7-Eleven、Lawson、MINISTOP、Seicomart、FamilyMart
※本服务使用株式会社 BPORTUS 提供的 PAYSLE。

在测试环境中，完成用户注册后即可立即试用所有支付方式。
如需在生产环境中使用，则须在开通卡片支付后，通过管理后台另行提交使用申请。

开始使用便利店支付

在开发过程中，便利店支付与 fincode 的卡片支付一样，可以简单地集成。
通过控制面板中的支付服务设置提交使用申请，审核完成后即可使用执行便利店支付的 API。

根据审核结果，可能无法使用该服务。审核期间如有需要进一步确认的事项，fincode 将通过电子邮件与您联系，请予以回复。 审核通常需要约 1～2 个月；如回复耗时较长，审核时间可能会进一步延长，敬请注意。

使用支付执行 API 时

在生产环境中，即使便利店支付审核已完成，也暂时无法使用便利店支付的支付执行 API。
这是因为在生产环境中，商户展示通过支付执行 API 响应获取的条形码时，需要由支付服务商进行条形码读取测试。
因此，如需在生产环境中使用支付执行 API，并由商户获取和展示条形码，则必须事先完成以下步骤。
※使用重定向方式时，无须执行以下步骤。

①申请使用支付执行 API

便利店支付审核完成后，请通过咨询表单联系我们，告知您希望使用支付执行 API。
收到您的联系后，我们将为您开通便利店支付的支付执行 API。

②由支付服务商进行条形码读取测试

完成步骤①后，请在生产环境中准备好能够获取和展示条形码的环境，然后再次通过咨询表单联系我们，申请进行条形码读取测试。
条形码展示页面请遵循此处的规范指南。
（预计测试周期：2～3 周）
