系统要求

使用 SDK 需要满足以下条件。

iOS

项目版本说明
平台iOS 14.0 及以上可使用 iOS SDK 的操作系统版本
Swift4.0 及以上可使用 iOS SDK 的语言版本

Android

项目版本说明
Android OS Version5Android OS 版本
minSdkVersion21运行所需的最低 API 级别
targetSdkVersion31目标 API 级别
compileSdkVersion31编译时使用的 API 版本

移动端 SDK（iOS SDK、Android SDK 和 React Native SDK）提供调用以下 API 的方法。

  • 执行支付
  • 3D Secure 认证
  • 确定认证结果
  • 认证后执行支付
  • 获取卡片列表
  • 登记卡片
  • 更新卡片

Node.js

项目版本说明
Node.js>= 12.0.0Node.js 版本 12 及以上

其他依赖项请参阅 GitHub 上的 package.json 。
