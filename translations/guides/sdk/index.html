fincode SDK

使用 fincode SDK 高效开发

fincode 为多种编程语言和框架提供 SDK（软件开发工具包）。SDK 提供类型定义以提高 API 请求与响应的安全性，提供符合各语言规范的 API 封装函数，还可生成卡片信息输入表单。这些功能可以加快支付接入，提高开发效率。
所有 SDK 均以 OSS（开源软件）形式提供，任何人都可免费使用。也可以随时通过 Issue 或 Pull Request 提出改进建议。

客户端 SDK

fincode 提供的客户端 SDK 如下。

  • iOS（Swift / Objective-C）SDK
  • Android（Kotlin / Java）SDK
  • 跨平台（React Native）SDK
  • ESModule SDK

客户端 SDK 提供类型定义、使用公钥调用 API 的封装函数，以及生成 UI 组件的功能，可加快 Web 应用和原生应用接入 fincode。

服务端 SDK

fincode 目前提供的服务端 SDK 如下。

  • Node.js（TypeScript/JavaScript）SDK

服务端 SDK 提供类型定义和使用私钥调用 API 的封装函数，提高核心支付流程的开发安全性和效率。类型定义和封装函数的参数等遵循 API 参考文档中的规范。

版本管理策略

各 fincode SDK 采用语义化版本管理。各版本号按以下规则递增。

  • 保持向后兼容的缺陷修复等：修订版本号
  • 保持向后兼容的功能新增：次版本号
  • 破坏向后兼容性的变更：主版本号
