关于 API 密钥

使用 fincode API 时，访问权限取决于请求附带的 API 密钥。API 密钥因用户而异，使用密钥即可以该用户的权限访问。
例如，应用需要访问 fincode 客户信息时，须由有权访问这些信息的用户签发 API 密钥。

认证方式

支持 Basic 认证和 Bearer 认证。
使用 Basic 认证时，指定经 Base64 编码的 API 密钥。使用 Bearer 认证时，将原始 API 密钥放入请求头。
请参阅以下示例。

Authorization: Basic {Base64でエンコードしたAPIキー}
Authorization: Bearer {APIキー}

API 密钥测试环境生产环境说明

版本管理

API 由主版本和次版本管理。

版本位置示例规则
主版本URIv1/products· 仅使用整数
· 系统全面更新时提升版本
· 提升版本时所有 API 都会更新版本（包括功能不变的 API）
次版本HTTP 请求头Api-Version: 20211001可指定的版本：20211001
· 不兼容的变更通过次版本处理
· 格式为发布日期 yyyymmdd
· 商户首次申请时，将当时最新的 API 版本记录为默认版本。
· 商户未指定版本时，应用默认版本。
