在测试环境注册新用户

使用 fincode 服务前，请先注册新用户。
测试环境和生产环境均须注册。

注册 fincode 新用户

打开控制面板的新用户注册页面后，输入姓名、电子邮件地址和密码，点击［注册新用户］。

选择商户类型

请选择商户类型。

标准类型：适用于普通商户运营。平台类型：适用于需要在 fincode 商户之间建立上下级关系，并以所有者身份管理商户的业务。

详情请参阅 平台 。

您在新用户注册时填写的电子邮件地址会收到 fincode（noreply@test.fincode.jp）发来的用户注册确认邮件。

邮件验证

点击邮件正文中的 URL，在打开的页面输入注册新用户时设置的密码，即可完成邮件验证。
完成邮件验证后即可登录管理后台。

登录成功后，测试环境的新用户注册即告完成。
