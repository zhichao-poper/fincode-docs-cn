准备接入 Apple Pay

开始准备接入 Apple Pay

要通过 fincode 在自有服务中接入 Apple Pay，需要在 Apple Developer Program 和 fincode 控制面板分别登记。
请参照下列流程完成登记。

  • 第 1 步：创建 Apple ID并注册 Apple Developer Program。
  • 第 2 步：创建 Apple 商户 ID
  • 第 3 步：创建证书签名请求（CSR）
  • 第 4 步：将 CSR 上传至 Apple Developer 网站，获取 Payment Processing Certificate
  • 第 5 步：在 fincode 登记 Payment Processing Certificate
  • 第 6 步：在网站使用时，在 Apple Developer 网站登记域名

第 1 步：创建 Apple ID 并注册 Apple Developer Program

为在生产环境使用 Apple Pay，请创建 Apple ID 并启用双重认证。创建方法请参阅 Apple 支持的“如何创建新的 Apple ID”页面。
创建 Apple ID 后，使用该账号注册并加入 Apple Developer Program。
后续签发 Apple 商户 ID 和获取 Payment Processing Certificate 时，均需要加入 Apple Developer Program。

第 2 步：创建 Apple 商户 ID

加入 Apple Developer Program 后，创建 Apple 商户 ID。此 ID 用于识别接受 Apple Pay 付款的商户。

  1. 前往 Apple Developer 网站的Certificates, Identifiers & Profiles，在侧边栏点击“Identifiers（标识符）”，再点击左上角“＋（添加）”。
  2. 选择“Merchant IDs”，点击“Continue（继续）”。
  3. 输入商户 ID 的说明（接入 Apple Pay 的应用简介）和 ID 名称，然后点击“Continue（继续）”。
  4. 核对设置内容，点击“Register（注册）”完成操作。

详情请参阅 Apple Developer 支持的“设置 Apple Pay ”页面。

第 3 步：创建证书签名请求（CSR）

创建 Apple 商户 ID 后，请按以下步骤创建 CSR 文件。之后签发 Payment Processing Certificate 时需要使用此文件。

  1. 在 Mac 上打开钥匙串访问，选择“从证书颁发机构请求证书”。
  2. 填写各项内容，勾选指定密钥对信息的选项，然后点击“继续”。
  3. 选定位置并保存，在密钥对信息中选择 ECC 算法、256 位密钥，再选择“继续”生成 CSR。
  4. 如果 Payment Processing Certificate 已过期，请重新按第 1 至第 3 项创建 CSR 文件。

第 4 步：将证书签名请求上传至 Apple Developer 网站，获取 Payment Processing Certificate

创建 CSR 后，按照以下步骤在 Apple Developer 上获取 Payment Processing Certificate※1。

  1. 前往 Apple Developer 网站的Certificates, Identifiers & Profiles，在侧边栏点击“Identifiers（标识符）”。
  2. 选择“Merchant IDs”，选中在“创建 Apple 商户 ID”步骤创建的商户 ID。
  3. 在“Apple Pay Payment Processing Certificate”中点击“Create Certificate（创建证书）”。
  4. 点击“Choose File（选择文件）”，上传第 3 步创建的 CSR 文件。
  5. 点击“Continue（继续）”。
  6. 点击“Download（下载）”，下载 Payment Processing Certificate（扩展名.cer），操作完成。
  7. 如果 Payment Processing Certificate 已过期※2，请重新创建 CSR 文件，并按第 1 至第 6 项重新获取 Payment Processing Certificate。

※1 Apple Developer 支持等资料也将 Payment Processing Certificate 称为支付处理证书。
※2 Payment Processing Certificate 的有效期为 25 个月。详情请参阅Apple Developer 的 Apple Pay 页面。

第 5 步：在 fincode 登记 Payment Processing Certificate

获取 Payment Processing Certificate 后，返回 fincode 控制面板登记证书，完成 Apple Pay 设置。

  1. 将第 4 步创建的 Payment Processing Certificate 登记到 Mac，打开钥匙串访问，并将其导出为 .p12 文件。导出时可自定密码短语。
  2. 在 fincode 控制面板侧边栏中，依次进入“商户设置 > 支付服务设置”。
  3. 点击“Apple Pay > 设置”。
  4. 点击“＋登记证书”。
  5. 在对话框中输入导出时使用的密码短语，上传导出的 .p12 文件。
  6. 点击“登记”完成登记。

※如果 Payment Processing Certificate 已过期，请重新获取证书并再次登记。

完成第 1 到第 5 步并通过审核后，即可使用 Apple Pay 付款。

第 6 步：在网站使用时，在 Apple Developer 网站登记域名

如果在网站上使用 Apple Pay※1，需要在 Apple Developer 网站将所有使用 Apple Pay 的域名（含子域名）关联到商户 ID。
关联后的域名称为商户域名。

  1. 前往 Apple Developer 网站的Certificates, Identifiers & Profiles，在侧边栏点击“Identifiers（标识符）”。
  2. 选择“Merchant IDs”，选中在“创建 Apple 商户 ID”步骤创建的商户 ID。
  3. 在“Merchant Domains（商户域名）”中点击“Add Domain（添加域名）”。
  4. 以完全限定域名（FQDN）格式输入使用 Apple Pay 的域名，然后点击“Save（保存）”。
  5. 点击“Download（下载）”下载域名验证文件。
  6. 将下载的域名验证文件放在https://[マーチャントドメイン]/.well-known/apple-developer-merchantid-domain-association。
  7. 点击“Verify（验证）”验证域名，操作完成。

详情请参阅 Apple Developer 支持的“在网页上设置 Apple Pay ”页面。
※1 在 Apple Developer 上称为 Apple Pay on the Web。
