执行支付处理

使用支付执行 API

fincode 中的银行转账支付流程如下。

  1. 买家选择银行转账作为支付方式。
  2. 商户调用 fincode 的登记支付接口。
  3. 商户指定支付 ID，调用 fincode 的执行支付接口。系统将签发与该支付关联的虚拟账户，并在响应中返回账户信息。
  4. 商户向买家展示签发的虚拟账户信息。
  5. 买家向该虚拟账户转账。
  6. fincode 发出 Webhook 事件通知。商户可以按需接收该事件并执行后续处理。

使用支付执行 JS

使用支付执行 JS，可以轻松地从前端应用接入银行转账。

  1. 买家选择银行转账作为支付方式。
  2. 商户调用 fincode 的登记支付接口。
  3. 商户指定支付 ID，调用 fincode 的支付执行 JS。系统将签发与该支付关联的虚拟账户，并在响应中返回账户信息。
  4. 买家向该虚拟账户转账。
  5. fincode 发出 Webhook 事件通知。商户可以按需接收该事件并执行后续处理。

沿用并复用账户信息

通常 fincode 每次执行登记支付都会签发新的虚拟账户，也可以沿用先前支付的虚拟账户。例如，需要持续向同一客户提供同一个虚拟账户时，可使用该功能。

如需复用账户信息，请在登记支付时，为可选参数再利用対象オーダーID（reference_order_id）指定上一笔支付的オーダーID（id）。
※被沿用账户信息的支付必须同时满足以下条件。

  1. 支付状态为売上確定（CAPTURED）／キャンセル（CANCELED）／期限切れ（EXPIRED）中的任意一种。
  2. 距买家向该账户转账入账之日不超过 90 天。

详细规格另请参阅API 参考（执行支付）－银行转账（虚拟账户）。
