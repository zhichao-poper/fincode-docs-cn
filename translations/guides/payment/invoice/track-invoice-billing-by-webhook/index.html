通过 Webhook 跟踪账单收费

账单功能提供多种 Webhook 事件，用于实时跟踪收费。接收这些事件，即可实时了解账单签发和支付情况。

账单功能的事件及其触发时间

事件名称事件触发时间账单状态
创建账单invoice.create在控制面板或通过创建账单 API 创建账单时此时status为DRAFT。
更新账单invoice.update在控制面板或通过更新账单 API 更新账单时此事件不会导致状态变化。
签发账单invoice.open在控制面板或通过签发账单 API 发起该账单的收费时此时status为AWAITING_CUSTOMER_PAYMENT。
账单已支付invoice.paid买家在支付页面完成付款，或在控制面板或通过 API 标记为外部支付时此时status为PAID。外部支付时，is_paid_externally还会变为true。
取消账单invoice.cancel在控制面板或通过取消账单 API 取消账单时此时status为CANCELED。
超过付款期限invoice.expired付款期限已过时此时status仍为AWAITING_CUSTOMER_PAYMENT，但仍可继续付款。

指定事件，并调用登记 Webhook 设置接口。指定事件发生时，通知将发送至指定 URL。
