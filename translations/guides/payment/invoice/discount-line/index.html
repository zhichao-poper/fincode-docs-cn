折扣明细（负数行）

账单功能支持添加金额为负数的明细行，将折扣等作为负数明细反映到账单中。无论按未税单价输入，还是按含税金额倒算，都可以使用折扣明细。

可在 fincode 控制面板或通过 API 使用折扣明细。创建账单的基本步骤请参阅使用账单功能。

如果任一税率的小计低于 0 日元，即该税率下的折扣超过应收金额，则无法签发账单。添加折扣明细时，请确保各税率的小计均大于或等于 0 日元。

在控制面板操作

在控制面板的账单创建或编辑页面添加负数明细行，即可设置折扣。

通过 API 指定

通过 API 创建账单时，可在创建账单（POST /v1/invoices）或更新账单（PUT /v1/invoices/{id}）中为明细指定负数金额，以添加折扣明细。
