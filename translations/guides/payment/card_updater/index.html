什么是卡片信息自动更新

当卡公司更新了商户客户名下已登记卡片的有效期或卡号时，fincode 的卡片信息自动更新功能会将 fincode 中的卡片信息更新为最新状态。

对开展订阅等定期扣费业务的商户，此功能可减少卡片过期导致的订阅收费失败，以及需要客户自行重新登记卡片信息的情况。

要使用卡片信息自动更新功能，请在 fincode 控制面板的支付服务设置中申请，审核通过后即可使用。审核结果可能导致该功能无法开通。

只有接收更新数据的卡公司持有相关信息时，才会更新卡片信息。

卡片信息自动更新与其他卡片信息更新方式的比较

卡片信息自动更新功能通过卡公司更新卡片信息，与卡片更新 API 是两项不同的功能。

卡片信息自动更新（洗替）卡片更新 API
概要从卡公司获得最新的卡片信息并更新 fincode 中的记录商户或客户自行通过 API 更新卡片信息
更新时间每月一次，在指定日期批量执行随时即时执行
指定对象的方式通过控制面板或 API 设置自动更新对象对每张卡片调用 API
使用场景减少订阅等持续使用的卡片发生过期的影响在客户提出更换卡片时立即处理

卡片自动更新日程

卡片自动更新每月按以下流程执行。

  1. 确定更新对象：每月在指定日期选取已设置为自动更新对象的卡片信息。
  2. 向卡公司发送数据：将符合条件的卡片信息批量发送给卡公司。
  3. 应用更新结果：卡公司返回的最新信息（有效期、卡号）自动应用到 fincode 的卡片信息。
  4. 通知结果：应用完毕后，通过 Webhook 通知更新结果汇总。

※此功能不会向客户自动收取设定金额。

日程

日期内容
每月 6 日卡片自动更新对象的设置截止日。请于此日前设置目标卡片。通常由 fincode 于每月 7 日处理。
每月 28 日起可以查看卡片自动更新结果。可通过 API 或控制面板查看。
※也会通过 Webhook 发送汇总通知。

卡片自动更新的判定规则

是否纳入卡片自动更新由以下设置的组合决定。

  • 商户级的卡片自动更新设置（商户设置）
  • 单张卡片的自动更新设置（card_updater_mode）

自动更新按商户客户名下登记的卡片逐张执行。
每张卡片的自动更新设置（card_updater_mode）与商户级的卡片自动更新设置共同决定该卡是否纳入更新范围。

卡片信息自动更新按商户管理。
即使同一客户在多家商户登记了相同卡片，也只会更新已设为更新对象的商户所登记的卡片信息。

平台类型的商户
对于平台类型的商户，管理者取决于是否共享客户信息。

■共享客户信息时
由平台（主商户）管理。
请由平台（主商户）设置自动更新对象。子商户和租户商户不能申请开通卡片信息自动更新功能。

■未共享客户信息时
按商户管理。
租户商户使用时，每个租户商户都需要分别申请开通卡片信息自动更新功能，并设置自动更新对象。

商户级卡片自动更新设置

在控制面板的“商户设置 > 支付服务设置”中，可启用或停用商户级卡片自动更新设置。此设置应用于自动更新设置为“继承商户设置”的卡片。

商户级卡片自动更新设置默认为“停用”。

单张卡片的自动更新设置

可通过控制面板或登记卡片、更新卡片（或登记支付方式、更新支付方式）API，逐张设置卡片的自动更新设置（card_updater_mode）。单张卡片的设置优先于商户级设置。
※通过支付方式 API 管理卡片的详情请参阅使用支付方式 API 处理卡片支付。

选项card_updater_mode 的值说明
启用更新enabled将此卡纳入自动更新范围。无论商户级设置如何，均执行自动更新。
停用更新disabled将此卡排除在自动更新范围之外。无论商户级设置如何，均不执行自动更新。
继承商户设置inherit（默认值）遵循商户级卡片自动更新设置。商户设置启用时纳入更新范围，停用时排除。
商户未指定时，卡片自动更新设置默认为“继承商户设置（inherit）”。

卡片信息自动更新的费用

卡片信息更新成功时，会产生卡片自动更新手续费。
如果仅检查更新，卡片信息未更新，则不收取手续费。
※详情请查看费率表。

卡片自动更新手续费会从 fincode 向商户支付的入账款中抵扣。如果该费用超过当期入账金额，fincode 会向已登记的账单收件方收费。
对于平台类型的商户，卡片自动更新手续费的账单收件方取决于是否共享客户信息。

共享客户信息
向平台（主商户）收费。

未共享客户信息
向各租户商户收费。平台可在卡片自动更新费用上加收款项，作为标准平台使用费从租户商户获得收入。
