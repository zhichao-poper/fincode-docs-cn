运营与注意事项

以下是使用 fincode 卡片信息自动更新功能时的运营方式与注意事项。

可使用卡片信息自动更新的商户

此功能仅供开展订阅等定期扣费业务的商户使用。
开通前需要审核。审核结果可能导致无法开通，或卡片支付手续费率发生变化。如有疑问，请联系 fincode。

哪些卡片信息会被更新

只有接收更新数据的卡公司持有该持卡人的信息时，卡片更新数据才会被应用。
并非所有卡片信息都会更新。使用 3D Secure 登记卡片时，处于等待客户验证状态的卡片无论如何设置，都不会纳入自动更新范围。

设置卡片自动更新对象的方法

使用 fincode 的卡片信息自动更新功能时，应通过控制面板或 API 预先设置目标卡片。该功能不使用文件上传方式，也不支持通过 CSV 等文件批量传送卡片信息。

与订阅功能配合使用

为用于持续收取订阅费用的卡片启用自动更新，可以减少卡片过期导致的订阅收费失败。即使自动更新成功，如果无法确认卡片有效，或未能获得授权，也无法扣费。

每月的设置日程

fincode 与卡公司之间的数据发送时间有严格规定。如果未能在指定时间前完成设置，需要等到下个月才能处理。必要时，请通知客户更新卡片。
