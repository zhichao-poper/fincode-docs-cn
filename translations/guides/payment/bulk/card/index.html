批量支付（卡片）

批量支付（卡片）可以对已登记卡片的客户一次执行多笔支付。
普通卡片支付需要对每笔支付调用 API。使用此功能，只需上传 JSON 文件即可集中处理大量卡片支付，减少 API 调用次数并提高处理效率。

使用此功能前，须申请开通 fincode 卡片支付并通过审核。

批量支付流程

1. 将需要批量处理的卡片支付信息汇总为 JSON 文件。
2. 调用登记批量支付接口，指定 JSON 文件和支付计划处理日期（process_plan_date）。
3. fincode 检查上传数据的格式。检查完成后，批量支付状态变为已检查（CHECKED）。
4. 到达 process_plan_date 后，系统对各笔支付执行授权。无法指定具体时间。
5. 全部处理完成后，批量支付状态变为已完成（COMPLETED）。

API 参数详情请参阅API 参考（登记批量支付）。

JSON 文件格式

上传的 JSON 文件以 multipart/form-data 格式发送，将支付信息列表放入 data 字段。
各项目的具体限制与登记支付和执行支付相同。

字段名称类型是否必填说明
idString订单 ID
amountString○使用金额
taxString税费和运费
item_codeString商品代码
customer_idString○客户 ID
card_idString卡片 ID（省略时使用默认卡片）
client_field_1String商户自定义字段 1
client_field_2String商户自定义字段 2
client_field_3String商户自定义字段 3

批量支付的状态

批量支付状态列表

批量支付整体可处于以下状态。

状态名称状态说明
检查中CHECKING正在检查上传的支付信息文件。
已检查CHECKED数据检查已完成，正在等待计划处理日期。只有此状态可以删除。
处理中RUNNING正在执行授权。
已完成COMPLETED全部处理完成。
错误ERROR检查数据时发生错误。

批量支付状态转换

下表列出各操作后的状态。“－”表示没有对应的结果或操作。

操作操作结果操作前状态操作后状态
登记批量支付成功－检查中
检查完成成功检查中已检查
错误检查中错误
到达计划处理日期－已检查处理中
全部处理完成－处理中已完成
删除批量支付成功已检查（已删除）

批量支付明细状态列表

批量支付内的各笔支付信息（批量支付明细）可处于以下状态。

状态名称状态说明
等待处理CHECKED正在等待授权处理。
成功SUCCEEDED授权处理成功。
失败FAILED授权处理失败。

查看处理结果

获取批量支付列表接口可查询已登记的批量支付；获取批量支付明细列表接口可查看指定批量支付内各笔支付的处理结果。
批量处理的支付与普通支付一样，可在控制面板的支付标签页或通过支付 API 查看，也可变更金额或取消。

API 详情请参阅API 参考（获取批量支付列表）。

注意事项

限制项目说明
登记截止时间须于支付计划处理日 01:00 前登记。
删除截止时间要停用已登记的批量支付，请在支付计划处理日 01:00 前执行删除。
删除后重新启用已删除的批量支付无法重新启用。请登记新的批量支付。
文件大小上限支付信息文件的大小上限约为 8 MB。超过上限时会返回状态代码 413。
