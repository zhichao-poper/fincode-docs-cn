执行支付处理

在 fincode 中，PayPay 支付流程从将买家跳转到 fincode API 返回的 PayPay 支付 URL 开始。
如果访问该 URL 的设备已安装 PayPay 应用，系统会直接启动应用，否则会打开 PayPay 网站的支付页面。

使用支付执行 API

  1. 买家选择 PayPay 作为支付方式。
  2. 商户调用 fincode 的登记支付接口。
  3. 商户调用 fincode 的执行支付接口。fincode 向 PayPay 请求签发支付 URL，并返回支払いURL(code_url)。
  4. 商户将买家重定向到支払いURL(code_url)。
  5. 跳转后，买家在 PayPay 应用或网站上付款，付款后跳转到リダイレクトURL(redirect_url)。
  6. PayPay 向 fincode 发送付款完成通知。
  7. fincode 将相应交易转为预授权或销售额已确认，并向商户发送付款结果通知。
