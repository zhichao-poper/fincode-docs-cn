使用支付方式 API 处理卡片支付

在卡片支付中，支付方式（Payment Method）表示与客户关联的已登记信用卡信息。
执行支付时指定支付方式 ID，即可使用对应卡片支付。

支付方式 API 兼容卡片 API的所有操作。新接入时，建议使用支付方式 API。

支付方式状态列表

表示卡片信息的支付方式可处于以下状态（status）。

状态名称状态说明
未激活INACTIVATED3DS 2.0 验证初始化失败。执行支付时无法指定此卡片。
等待客户操作AWAITING_CUSTOMER_ACTION3DS 2.0 验证初始化成功，正在等待客户完成 3DS 验证。执行支付时暂时无法指定此卡片。リダイレクト先URL（redirect_url）可用时，请将客户引导至 3DS 验证页面。
已激活ACTIVATED卡片已激活。可指定此支付方式 ID 执行支付。

CHALLENGE（执行挑战验证）买家需要进行额外验证（挑战）。

使用 API

登记卡片

在登记支付方式（POST /v1/customers/{customer_id}/payment_methods）的请求体中，将 pay_type 设为 Card ，即可为指定客户登记卡片信息。

登记时的 3DS 验证由 3DS認証設定（tds_type） 指定。tds_type 将 2 设为此值时，登记会使用 3DS 验证。用于跳转至 3DS 验证页面的 リダイレクト先URL（redirect_url） 将包含在响应中。请引导客户访问此 URL 完成 3DS 验证。tds_type 未指定此值时，登记不使用 3DS 验证。登记成功后，支付方式状态会直接变为有効化済み（ACTIVATED）。

获取已登记卡片的列表或单张卡片

在获取支付方式列表（GET /v1/customers/{customer_id}/payment_methods）中指定 pay_type=Card ，即可获取客户已登记的卡片列表。
获取支付方式（GET /v1/customers/{customer_id}/payment_methods/{payment_method_id}）可以获取指定支付方式 ID 的一条卡片信息。

获取结果的响应中， card 字段包含卡片状态和 3DS 验证状态等信息。

更新卡片信息

更新支付方式（PUT /v1/customers/{customer_id}/payment_methods/{payment_method_id}）可更新卡片信息。

执行有效性检查（授权）的条件

是否执行有效性检查（授权）取决于更新请求所包含的参数。

更新请求包含以下参数时会进行有效性检查。

  • token（卡片令牌）
  • default_flag（默认标志）
  • holder_name（持卡人）
  • expire（有效期）

更新请求只更改以下参数时不会进行有效性检查。

  • card_updater_mode（卡片自动更新设置）
  • client_field_1 〜 client_field_3（商户自定义字段）

指定 tds_type

如果更新请求会执行有效性检查，则必须指定3DS認証設定（tds_type） 。tds_type 将 2 设为此值时，会执行 3DS 重新验证，リダイレクト先URL（redirect_url） 将包含在响应中。请引导客户访问此 URL 完成 3DS 验证。

删除卡片

删除支付方式（DELETE /v1/customers/{customer_id}/payment_methods/{payment_method_id}）可删除卡片。

删除默认卡片时，如果客户还登记了其他卡片，系统会自动将另一张设为默认卡片。

自动更换默认卡片时不考虑卡片状态。“未激活（INACTIVATED）”或“等待客户操作（AWAITING_CUSTOMER_ACTION）”的卡片可能被设为默认卡片。可考虑在删除前先将其他卡片设为默认卡片。

设置卡片信息自动更新

在登记支付方式或更新支付方式的请求中指定 カード更新設定（card_updater_mode） ，可以逐张控制是否将卡片纳入自动更新。

设置值说明
enabled将此卡纳入自动更新范围。无论商户级设置如何，均执行自动更新。
disabled将此卡排除在自动更新范围之外。无论商户级设置如何，均不执行自动更新。
inherit（默认值）遵循商户级卡片自动更新设置。

card_updater_mode 是唯一变更项时，更新请求不会执行有效性检查（授权）。
关于卡片信息自动更新的详情，请参阅什么是卡片信息自动更新。

Webhook 事件

对卡片支付方式执行操作或完成验证时，会发送以下 Webhook 事件。

事件名称发送时间
customers.payment_methods.updated卡片登记、更新、删除或 3DS 验证完成时
card.update卡片信息自动更新结果确认时

customers.payment_methods.updated 该事件的载荷包含支付方式对象（卡片）。
card.update 有关事件详情，请参阅通过 Webhook 接收卡片自动更新结果。

有关 API 详情，请参阅API 参考（支付方式）。
