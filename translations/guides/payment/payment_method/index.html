什么是支付方式（Payment Method）

支付方式（Payment Method）是表示客户名下已登记收费对象信息的实体。执行支付时指定支付方式 ID（payment_method_id），即可使用该支付方式收费。
各支付功能对支付方式的处理如下。

支付功能pay_type支付方式实体对应的信息说明
卡片支付Card卡片（信用卡）信息決済種別（pay_type）为Card的支付方式（Payment Method）。
已登记卡片信息作为卡片对象处理。详情请参阅使用支付方式 API 处理卡片支付。
Apple PayApplePay－（Apple Pay 目前不支持支付方式 API。）
便利店支付Konbini－（便利店支付目前不支持支付方式 API。）
PayPayPaypay－（PayPay 目前不支持支付方式 API。）
银行账户自动扣款Directdebit自动扣款账户信息決済種別（pay_type）为Directdebit的支付方式（Payment Method）。
表示通过 Web 登记或申请书登记在客户名下的自动扣款账户。
银行转账（虚拟账户）Virtualaccount为客户签发的虚拟账户決済種別（pay_type）为Virtualaccount的支付方式（Payment Method）。
表示为客户持续保留的虚拟账户。详情请参阅使用支付方式 API 管理客户的固定虚拟账户。

支付方式对象的结构

支付方式对象包含所有受支持支付功能共有的字段，以及各项支付功能专用的字段。共有字段位于对象顶层，专用字段位于以对应支付功能命名的字段下。

参数类别参数名称对应的支付功能概要
共有参数id－支付方式（Payment Method）ID
created－此支付方式的创建时间
updated－此支付方式的更新时间
pay_type－支付类型
process_date－处理时间
return_url－成功时的商户返回 URL（通过 POST 跳转）
return_url_on_failure－失败时的商户返回 URL（通过 POST 跳转）
redirect_url－跳转 URL
将最终用户引导至此 URL，以完成支付方式登记。
redirect_url_accessed_flag－跳转 URL 已访问标志
表示是否至少访问过一次跳转 URL。
用于判断仅可访问一次的跳转 URL 是否已使用，例如银行账户自动扣款的跳转 URL。
status－支付方式状态
此值为ACTIVATED时，可指定该支付方式 ID 执行支付并收费。
default_flag－默认标志
表示是否默认使用此支付方式。执行支付时如果只指定客户 ID，未指定支付方式 ID，系统会自动使用此值为1的支付方式收费。
client_field_1－商户自定义字段 1
client_field_2－商户自定义字段 2
client_field_3－商户自定义字段 3
专用参数directdebit银行账户自动扣款包含自动扣款账户专用字段的对象。
包含金融机构代码、分行代码、账号等信息。
card卡片支付包含卡片支付专用字段的对象。
包含卡号末四位、有效期、3DS 验证状态等信息。
virtualaccount银行转账（虚拟账户）包含为客户签发的虚拟账户专用字段的对象。
包含分行代码、账号和账户户名等信息。
