在生产环境公开支付功能

要正式启用支付功能，请从测试环境切换到生产环境。
请注意，在生产环境执行支付会产生实际扣款。

在测试环境执行支付。请按该页步骤在测试环境执行支付并核对结果，然后再切换到生产环境。

从测试环境切换到生产环境

生产环境和测试环境的区别如下。

类别测试环境生产环境
API 端点 URLapi.test.fincode.jpapi.fincode.jp
API 密钥从测试环境的管理后台获取从生产环境的管理后台获取
电子邮件地址noreply@test.fincode.jpnoreply@fincode.jp

将 API 端点 URL 和 API 密钥更新为生产环境的值，并设置允许接收来自相应域名的电子邮件。
从测试环境到生产环境的切换即告完成。

商户收到实际订单并完成支付处理后，即可查看销售款。
