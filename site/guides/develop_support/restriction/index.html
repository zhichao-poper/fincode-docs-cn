限制事项

关于测试环境

测试环境的行为可能与生产环境不同。
测试环境可能在未事先通知的情况下变更或维护。
请勿用于会产生大量请求的负载测试等。

流量控制与速率限制

fincode 将每个商户的请求限制为每秒 5 次。

超时

调用 API 时，建议将超时时间设置为 90 秒。该值考虑了发卡机构的授权处理时间。

事件与日志

控制面板中的事件与日志保留约 1 个月。
超过 1 个月的数据可能会在未事先通知的情况下被删除。
