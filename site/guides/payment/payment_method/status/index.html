查看支付方式状态

支付方式（Payment Method）具有状态。通过检查支付方式对象中的status字段，可以判断该支付方式是否可用于收费等。

支付方式状态列表

支付方式可处于以下状态。

状态名称状态说明
未激活INACTIVATED支付方式已登记给客户，暂时无法指定为收费对象。
等待客户操作AWAITING_CUSTOMER_ACTION正在等待客户批准登记支付方式等操作，暂时无法指定为收费对象。
redirect_url可用时，将客户引导至该 URL。
已激活ACTIVATED支付方式已生效。
执行支付时可以指定该支付方式 ID 作为收费对象。
失败FAILED支付方式激活失败，无法指定为收费对象。只能通过 API 或控制面板执行删除。
