使用卡片信息自动更新

您可通过 fincode 控制面板或 API 设置自动更新对象，并查看更新结果。此功能需要申请开通，只有通过审核才可使用。

从控制面板使用卡片信息自动更新

您可以在 fincode 控制面板配置商户级卡片自动更新设置，以及单张卡片的自动更新设置。

1. 更改商户级的卡片自动更新设置

登录 fincode 控制面板后，从“商户设置”打开“支付服务设置”。点击“卡片信息自动更新”的“设置”按钮，可启用或停用商户级卡片自动更新设置。

选项说明
启用自动更新设置为“继承商户设置（inherit）”的卡片将纳入自动更新范围。
停用自动更新设置为“继承商户设置（inherit）”的卡片将排除在自动更新范围之外。

变更后，请在“支付服务设置”页面中确认“卡片信息自动更新”的商户级设置状态已反映变更。

2. 更改单张卡片的自动更新设置

控制面板侧边栏的“支付方式 > 卡片”会列出与商户已登记客户关联的卡片。可逐张设置或更改卡片的自动更新设置。

请设置为以下任一选项。

选项说明
启用更新将此卡纳入自动更新范围。无论商户级设置如何，每月均执行自动更新。
停用更新将此卡排除在自动更新范围之外。无论商户级设置如何，均不进行自动更新。
继承商户设置遵循商户级卡片自动更新设置。商户设置启用时纳入更新范围，停用时排除。

商户未指定时，卡片自动更新设置默认为“继承商户设置（inherit）”。商户级设置为“启用”时，未指定设置的已登记卡片将自动纳入更新范围。

3. 在控制面板查看卡片自动更新结果

在控制面板侧边栏的“支付方式 > 卡片”中，可以查看各卡片的自动更新时间和更新成功时间。卡片纳入更新范围后，其卡片信息会记录“卡片自动更新时间”；卡片信息更新后，会记录“卡片自动更新成功时间”。
※只有卡片自动更新成功时，更新成功时间才会刷新。

使用 API 进行卡片信息自动更新

从设置更新对象到查看结果的流程如下。

  1. 在登记卡片或更新卡片接口中指定card_updater_mode，设置单张卡片是否纳入自动更新范围。
  2. 每月指定日期自动执行卡片更新，并应用最新信息。
  3. card.updater.complete通过 Webhook 接收该事件，了解尝试更新的卡片数和成功更新的卡片数。
  4. 获取卡片、获取卡片列表及获取卡片列表（按客户信息共享组）的结果中可查看尝试更新时间和更新时间，以确定单张卡片的更新结果。

对商户已登记的所有卡片生效的商户级卡片自动更新设置只能在控制面板启用或停用。如需更改，请在控制面板操作。

逐张设置卡片自动更新对象

在登记卡片或更新卡片的请求参数中指定card_updater_mode，逐张设置卡片是否纳入自动更新范围。
※如果要纳入商户已登记的全部卡片，只需设置商户级卡片自动更新。

参数名称类型是否必填说明
card_updater_modeString-该卡片的自动更新设置。enabled（启用更新）／ disabled（停用更新）／ inherit（继承商户设置）三者任选其一。

商户未指定时，card_updater_mode默认为“inherit（继承商户设置）”。商户级卡片自动更新设置为“启用”时，未指定设置的已登记卡片将自动纳入更新范围。

※card_updater_mode可以在申请开通卡片信息自动更新前设置此字段。只有审核通过后，此设置才用于判定是否更新。

查看卡片自动更新结果

通过卡片信息查看结果

可通过获取卡片、获取卡片列表及获取卡片列表（按客户信息共享组）响应中的以下参数查看卡片自动更新结果。

参数名称类型说明
card_updater_modeString该卡片的自动更新设置。enabled / disabled / inherit 中的任意一种。
card_updater_last_attempt_dateString最近一次尝试自动更新的日期和时间。记录上次尝试自动更新此卡的时间。
card_updater_last_success_dateString最近一次自动更新成功的日期和时间。记录卡片信息实际自动更新的最后时间。

区分所有尝试更新的卡片和成功更新的卡片

可通过以下步骤区分系统尝试更新的全部卡片，以及其中卡片信息实际更新的卡片。

  1. 获取卡片列表（按客户信息共享组）接口中，在card_updater_last_attempt_date_from、card_updater_last_attempt_date_to指定目标月份的范围，即可取得尝试自动更新的全部卡片。
  2. 取得的卡片中，card_updater_last_success_date落在目标月份的卡片即为卡片信息实际更新的卡片。

以下为查询条件示例。

获取卡片列表 API 查询参数名示例含义
card_updater_last_attempt_date_from2026-03-01尝试自动更新的起始日期。查询该时间及之后尝试自动更新的卡片。
card_updater_last_attempt_date_to2026-03-31尝试自动更新的结束日期。查询该时间及之前尝试自动更新的卡片。
