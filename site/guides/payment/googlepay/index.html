Google PayTM简介

Google Pay 是一种使用买家 Google 账号中保存的信用卡信息完成付款的支付方式。

在 fincode 中，Google Pay 支持以下国际卡组织。
VISA(ビザ), Mastercard(マスターカード), JCB(ジェーシービー),Diners Club(ダイナースクラブ) ,American Express(アメリカンエキスプレス)

在测试环境中，注册后即可试用所有支付方式。
要在生产环境使用，需先开通卡片支付，再从控制面板另行申请。

开通 Google Pay

在生产环境接受 Google Pay 之前，请在控制面板的支付服务设置中提交开通申请。
申请通过审核后，即可使用 Google Pay 支付。

Google Pay 的支付流程是在支付执行 API 的请求中传入通过 Google Pay API 获取的令牌。使用 Google Pay API 时，必须遵守 Google Pay API 的使用政策，并同意使用条款中列明的条件。

部分国际卡组织可能因审核结果而无法使用。可用卡组织通常与卡片支付的审核结果一致。
审核通常约需 1 个工作日。
