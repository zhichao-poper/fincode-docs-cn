限制事项

将银行转账集成到服务前，请务必确认银行转账（虚拟账户）支付的以下限制。

限制项目说明
可用金额1 日元至 9,999,999,999 日元（要求转账金额与转账所需税费和运费之和）
付款有效天数1 至 99 天
可在执行支付时指定，未指定时为 90 天。
从执行日起计算，在经过指定天数后的次日上午到期。
例如，2024/4/1 使用支払期限日数=2执行支付时，将于 2024/4/4 上午到期。
虚拟账户的签发银行虚拟账户由 GMO 青空网络银行签发。
会向买家提供 GMO 青空网络银行的账户信息。
账户户名账户户名如下。
口座名義：明細書表記（店舗名カナ）/ｼﾞｰｴﾑｵｰｲﾌﾟｼﾛﾝ(ｶ
• 显示每家商户申请时提供的“账单显示名称（店名假名）”。
• “账单显示名称（店名假名）”的前 24 个字符以半角片假名显示，第 25 个字符起截去。
• 户名末尾会自动附加“/ｼﾞｰｴﾑｵｰｲﾌﾟｼﾛﾝ(ｶ”。
• “账单显示名称（店名假名）”中的长音符号会转换为半角连字符（减号）-，账户以转换后的户名签发。
可复用虚拟账户的支付条件可复用虚拟账户的支付须满足以下条件。
1. 支付状态为売上確定（CAPTURED）／キャンセル（CANCELED）／期限切れ（EXPIRED）中的任意一种。
2. 距买家向该账户转账入账之日不超过 90 天。
要求转账金额与实际入账金额不一致时• 登记虚拟账户支付信息时指定的要求转账金额
• 买家实际转账的入账金额
即使二者不一致，fincode 仍会将该笔交易标记为売上確定（CAPTURED）。
可查看获取支付信息 API 或入账 Webhook 中的振込依頼金額（billing_amount）与利用金額（amount）的差额，判断入账金额是否有多付或少付。
定期维护GMO 青空网络银行在下列时段进行定期维护。
【生产环境】
每月第二个星期六 21:50 至次日星期日 06:00
※上述时段内，执行支付及取消支付 API 会返回错误（错误代码：EG002550001 或 E9991001003）。
买家仍可向已签发的账户付款，但转账结果会在维护完成后才反映到控制面板，并发送 Webhook 通知。

【测试环境】
每周四 16:00 至 18:00
※上述时段内，执行支付及取消支付 API 会返回错误（错误代码：EG002550001 或 E9991001003）。
此外，在控制面板中执行银行转账支付也会失败。
