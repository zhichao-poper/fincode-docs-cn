什么是可入账金额设置

可入账金额设置要求转入虚拟账户的金额与应收金额完全一致。
如果买家向启用此功能的虚拟账户汇入的金额与应收金额不一致，fincode 不会完成支付，GMO 青空网络银行会自动将转账款项退回汇款人。

出现入账金额不一致时，无需人工核对或退款，尤其可以减轻客户量较大的业务的运营负担。

这是可选功能，按使用量收费。

适用功能

以下功能支持可入账金额设置。

功能支持情况
虚拟账户支付（支付登记 API）支持
跳转式支付 URL支持
账单功能支持
批量支付（虚拟账户）支持

设置方法

要在相应功能中启用可入账金额设置，请在对应 API 的请求参数中指定 use_exact_deposit_amount: true 。

虚拟账户支付（支付登记 API）

执行支付（PUT /v1/payments/{id}）的请求体中指定 use_exact_deposit_amount: true 。

跳转式支付 URL

创建支付 URL（POST /v1/sessions）请求体的 virtual_account 对象中指定 use_exact_deposit_amount: true 。

买家在支付 URL 的页面选择虚拟账户支付时，可入账金额设置将应用到签发的虚拟账户。

通过控制面板创建邮件链接时，也可以启用可入账金额设置。请在“支付方式”中选择“银行转账（虚拟账户）”，再设置随后出现的“可入账金额设置”。

账单功能

创建账单（POST /v1/invoices）或更新账单（PUT /v1/invoices/{id}）请求体的 embedded_virtual_account 对象中指定 use_exact_deposit_amount: true 。
请在签发账单前设置。账单签发后无法更改。

也可以在控制面板创建或编辑账单时启用可入账金额设置。在创建或编辑账单页面的“设置账单详情”区块中选择“银行转账（虚拟账户）”，再设置随后出现的“可入账金额设置”。

批量支付（虚拟账户）

登记批量支付（POST /v1/payments/bulk）上传的 JSON 文件中，为每笔支付信息指定 use_exact_deposit_amount: true 。
可以逐笔设置。

入账时的行为

金额一致时

应收金额与转账金额一致时，支付会按普通虚拟账户支付的流程完成。

功能完成后的状态
虚拟账户支付（支付登记 API）、批量支付売上確定（CAPTURED）
跳转式支付 URL支払い完了
账单功能支払い済み（PAID）

金额不一致时

应收金额与转账金额不一致时，支付状态保持原样，也不会发送 Webhook 等通知。买家尝试转账时所使用的金融机构会向汇款人发出转账失败通知。
