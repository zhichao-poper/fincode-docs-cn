限制事项

可在此查看相关限制事项。

限制对象说明
可用金额1 日元～99,999,999 日元（使用金额与税费及运费的合计）
※根据店铺连接的卡片公司（收单机构），单次可用金额的上限有时为 9,999,999 日元。
从开始本人认证到支付的时间900 秒
显示本人认证密码输入页面后，如果经过 900 秒以上，支付将无法正常完成。
可用品牌VISA
MasterCard
JCB
American Express
Diners Club
Discover
可指定的分期付款期数（付款次数）3、5、6、10、12、15、18、20、24 期

※根据店铺的审核结果，某些品牌可能无法使用分期付款。
※根据购买者与发卡机构的合同内容等，可能无法使用分期付款。
可使用 EMV 3-D Secure 的品牌VISA(Visa Secure)
MasterCard(Mastercard ID check)
JCB(J/Secure)
American Express(American Express SafeKey)
Diners Club(ProtectBuy)
Discover(ProtectBuy)
重试输入 EMV 3-D Secure 密码取决于发卡机构。
同时使用 PIN 码和 EMV 3-D Secure不支持
只有在签约时设置为使用 PIN 码的店铺才能使用 PIN 码。
将“预授权”状态的交易更改为“请款完成”的期限25 天
当天按第 0 天计算。

超过可更改期限后执行“请款”将发生错误。如果预计运营中可能超过 25 天，需要先取消预授权，然后再次执行授权。
此外，如果时间间隔较长，再次授权时可能会因卡片状态而发生有效期错误或超出额度等错误。
由于具体原因涉及个人信息，请持卡人本人联系卡面所载的发卡机构。
可对“预授权”状态的交易执行“取消”和“修改金额”的期限180 天（交易保留期限）
当天按第 0 天计算。
可对“请款完成”状态的交易执行“取消”的期限180 天（交易保留期限）
当天按第 0 天计算。
可对“请款完成”状态的交易执行“修改金额”的期限180 天（交易保留期限）
当天按第 0 天计算。
可对“已取消”状态的交易重新授权的期限180 天（交易保留期限）
当天按第 0 天计算。
每笔交易的历史记录数
（取消、重新授权等操作的次数）		无限制
关于删除交易无法删除交易。即使结果发生错误也不例外，请注意。
因此，请勿将订单编号等无法更改的编号用作订单 ID。如确实必须使用，建议采用“订单编号 + 连号”等编号规则。
关于卡号限制API 和控制面板中显示的卡号，将以除末 4 位之外均被掩码的格式返回。
