强制使用 3D Secure 时的行为

fincode 完成卡片支付审核后，有时会要求商户接入 3D Secure，作为使用卡片支付的条件。有此要求的商户在处理卡片支付时会受到相应限制，接入时须按限制处理。

确认是否强制使用

如果商户必须接入 3D Secure，可以通过以下任一方式确认。

  • 商户审核暂缓时，fincode 会通过电子邮件通知。
  • 在控制面板的卡片使用设置中，3D Secure 使用设置会显示“必需”。
    ※卡片支付审核完成后，结果才会显示在控制面板中。
测试环境中的 3D Secure 使用设置默认为“可选”，生产环境默认为“必需”。
因此在生产环境中，未逐笔执行 3D Secure 验证的支付通常会报错。

支付处理限制

强制使用 3D Secure 时，系统会限制卡片支付。未执行 3D Secure 验证的交易不会进行授权，并会返回支付错误。因此在接入 3D Secure时，支付登记 API 的请求体需要作如下设置。

  • tds_type（3Dセキュア利用種別）设置为2: 3Dセキュア2.0を利用する。
  • tds2_type（3Dセキュア2.0非対応時の動作）建议设置为2:エラーを返し、決済処理を行わない。
    ※ 3: 3Dセキュア2.0の認証なしでオーソリを実施し、決済処理を行う：即使指定此值，使用不支持 3D Secure 的卡片支付仍会报错。
有关支付登记 API 的规格，请查看API 参考。
