UI 组件

使用 UI 组件进行支付

UI 组件是嵌入式卡片信息输入表单。
使用 fincode JS，可在商户自行搭建的支付页面中嵌入卡片信息输入表单并执行支付。

  • 查看 JavaScript 参考

1. 显示支付页面时，先调用 fincode JS 初始化 UI。
2. 创建输入表单，生成输入表单信息。
3. 将 UI 挂载到支付页面。
4. 买家在输入表单中填写卡片信息。
5. 获取输入表单信息，取得买家填写的内容。
6. 调用 fincode JS 执行支付。

创建并放置 UI 组件

要使用 UI 组件，请在 HTML 中添加 form 及一个空的 div。
使用 iframe 的 UI 组件将插入该 div。详情请参阅JavaScript 参考。

UI 组件（client.js）

var fincode = Fincode(<パブリックキー>)
var ui = fincode.ui({layout: "vertical"})
ui.create("payments",{layout: "vertical"})
ui.mount("fincode",'400')

初始化 fincode JS，并初始化 UI 组件。
要将 UI 组件插入已设置的 div，请创建输入表单并挂载 UI。

获取 UI 组件信息并执行支付

要进行支付，需要将支付登记 API和获取输入表单信息的响应传给支付执行函数。

取得输入表单信息后，调用 fincode JS 执行支付，支付处理即告完成。

有关支付执行的详细信息，请查看测试环境执行支付。

UI 组件（client.js）

// 入力フォーム情報を取得する
await ui.getFormData().then(result => {
     transaction={
        access_id: payment.access_id,

        pay_type: payment.pay_type,

        card_no: result.cardNo,
        security_code: result.CVC,
        expire: result.expire,
